# Independent IFC regression — Integrated121
Reproduces the milestone 126 audit of the exact experimental IFC export (not a universal IFC validator). Node.js and web-ifc 0.0.81, MPL-2.0, installed separately with the lockfile and scripts disabled: npm ci --ignore-scripts --no-audit --no-fund. Run node audit-integrated121.cjs "<path-to-Integrated121-ifc>". The file is read locally only. Package source: https://github.com/ThatOpen/engine_web-ifc . Do not commit node_modules or project IFC data.
The fixture is expected to contain the exact 18 Revit element tags from milestone 121, nominal door dimensions, three storeys and millimetre length units. Checks relationship targets, geometry buffers, axes vs. bodies, and door filling relationships. Does not prove full schema conformity, exact material appearance or full round-trip. The independent reader reported GetColor unexpected style type 3100; geometry/relationship checks passed. Keep that issue open under interoperability item 070.
