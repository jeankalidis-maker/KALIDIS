# FamFab source integration review (151)

Source-only review at kilkellym/ArchSmarterFamFab 5b7824db403692e76138cef79ace346c76e6890f (MIT). License retained in THIRD-PARTY-FamFab.txt. The example-cabinet.json in this folder is from the repository's docs/reference/skill_extracted/revit-family-generator/references/example-cabinet.json.

The upstream UI uses WebView2 and an Anthropic BYOK client; its build includes a post-build add-in copy. Do not build or install that add-in wholesale. Use the existing Kalidis engine and the local JSON path instead. No API key, external API call, paid provider or image upload introduced by this adapter. The upstream README describes per-call provider costs as model/image dependent; no current quote was obtained. This source review is not a review of external-provider pricing.

Converted: schema 0.1 numeric defaults, arithmetic expression evaluation without eval, unit conversion, all three principal axes for extrusion/blend/sweep recipes, rectangular/circular/L/custom extrusion profiles, polygonal blends, centered circle/rectangle sweeps, straight and unambiguous minor arc paths, named reference planes, explicit subcategories, explicit cut groups, category/template guard. Native extensions for axes, subcategories, reference planes and typed parameters compiled, not yet live-tested. Native formulas and driving constraints remain limited to the existing explicitly supported z-axis mechanisms. Unconverted source constraints and reference designations are reported rather than silently treated as implemented. Parameter groups map to Data and are reported; material defaults, ambiguous sweeps/blends, and unresolved voids refused. No automatic image-to-definition or interactive WebView2 preview claimed.

Exact upstream example statically converted and MCP validated: six positive solids, three subcategories, eight planes; the Toe Kick Void has zero positive volumetric overlap with the six rectangular solids, explicitly omitted; three alignment constraints reported not applied. Expected bounds 609.6 x 628.65 x 812.8 mm, sum of disjoint solid volumes 0.04347270438506248 m3. Native creation on the next DLL and independent geometry/category/subcategory review remain required.
